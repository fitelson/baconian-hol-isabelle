# Secondary and historical HOL-ZF models

This directory is not the official formalization of Bacon's appendix model.
It contains:

- the earlier full, hyperintensional, Boolean-tree, and natural-word frames;
- finite-fragment and stock-enlargement experiments built over those frames;
- Goodman-specific L2, M1, M5, M7, classifier, and absorption investigations;
- `Bacon_PP_Central_Model_Obligations`, the abandoned universal
  closure-code/PER carrier program.

These theories remain useful as comparison results, counterexamples,
calibration lemmas, and records of the route to the exact construction.  A
theorem proved only here is not thereby a theorem about Bacon's appendix
model.  Any transfer to the canonical model must be separately proved over
the carriers in `../canonical/`.
