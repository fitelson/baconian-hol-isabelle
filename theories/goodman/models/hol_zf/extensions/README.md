# Goodman extensions of Bacon's exact model

These theories interpret Goodman's vocabulary over the exact Bacon carriers
from `../canonical/`:

- `Bacon_PP_ZF_Exact_Logical_Stock`: the stock generated by closed logical
  terms;
- `Bacon_PP_ZF_Exact_Logical_Stock_Action`: action invariance of closed
  denotations;
- `Bacon_PP_ZF_Exact_Generic_Seed`: the generic fundamental proposition and
  its internal interpretation;
- `Bacon_PP_ZF_Exact_Recombination`: Recombination, Exhaustion, QLN, and the
  exact Goodman background package.

This directory introduces no alternative carrier, application operation, or
equivalence relation, and it does not import the secondary development.
