# Primary source PDFs

This directory contains the documents used for the project's
source-fidelity audits. Stable repository paths allow a fresh user or research
agent to check the Isabelle encodings and report against the same texts.

## Documents

### Jeremy Goodman, project notes

[Goodman_PP_Project_Notes.pdf](pdfs/Goodman_PP_Project_Notes.pdf)

Jeremy Goodman, “Is Purity of Pure consistent with Bacon's Logical
Combinatorialism?”, state-of-project notes, July 2026. These notes state the
central consistency question and the T- and M-claims audited by the project.

[Bacon_Dorr_Classicism.pdf](pdfs/Bacon_Dorr_Classicism.pdf)

### Andrew Bacon, *Logical Combinatorialism*

[Bacon_Logical_Combinatorialism.pdf](pdfs/Bacon_Logical_Combinatorialism.pdf)

Andrew Bacon, “Logical Combinatorialism,” *The Philosophical Review* (2020).

### Daniel Kirchner, “Computer-Verified Foundations of Metaphysics”

[Kirchner_Computer_Verified_Foundations_of_Metaphysics.pdf](pdfs/Kirchner_Computer_Verified_Foundations_of_Metaphysics.pdf)

Daniel Kirchner, “Computer-Verified Foundations of Metaphysics,” *KI --
Künstliche Intelligenz* 38 (2024): 95--98,
<https://doi.org/10.1007/s13218-024-00834-z>. This article describes
Kirchner's construction of the custom AOT theorem-proving environment in
Isabelle/HOL, including its shallow semantic embedding and abstraction layer.
It is the principal methodological source for the imported AOT formalization.

SHA-256:
`b460eddcddc8ab8db8fcfcc8924d9444dfdf1da3acb222bbc3d9fef44fad3572`
